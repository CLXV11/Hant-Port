# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability

Report vulnerabilities by opening a private security advisory:
https://github.com/CLXV11/Hant-Port/security/advisories/new

Do **not** open public issues for security problems.

## Scope

HANT PORT is a reconnaissance tool. It intentionally contains no
exploitation functionality and sends no destructive payloads. Reports about
"missing attack features" will be closed.
